احمِ البلاغات بكلمة مرور

اختار كلمة مرور قوية وشاركها مع الفنيين فقط، بعيد عن لينك الموقع. مش بنحفظها في المتصفح ولا في الكود. لو نسيتها، ارفع الشيت تاني بكلمة جديدة.

٣

انشر على GitHub

  1. بعد التنزيل، افتح صفحة رفع الملفات بزرار «فتح GitHub».
  2. اختار الملف المشفر اللي نزل باسم latest.enc.json فقط، مش ملف Excel.
  3. اضغط Commit changes. لو الملف موجود، GitHub هيستبدله بالنسخة الجديدة.
  4. استنى النشر يخلص، وافتح الموقع واتأكد إن تاريخ الشيت اتحدث. ده ممكن ياخد شوية دقايق.
فتح GitHub لرفع الملف المشفر ↗

دي خطوة بتحتاج دخولك لحساب GitHub صاحب الموقع. صفحة الرفع دي مش بتدي الزائر صلاحية تعديل الموقع. مفيش حاجة اسمها توكن مطلوب هنا.

النسخ القديمة المشفرة بتفضل في تاريخ GitHub. تغيير كلمة المرور بيحمي الشيت الجديد فقط، ومش بيسحب بيانات حد فتحها قبل كده. استخدم استضافة بصلاحيات دخول لو محتاج سحب الوصول لكل فني لوحده.
البيانات الأصلية تفضل على جهازك. ارفع النسخة المشفرة فقط.
